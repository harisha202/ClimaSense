Architecture

ClimaSense is architected using enterprise-grade design patterns for high availability, security, and responsive UX:

  • Modular Flask Blueprints: Clean separation of concerns across authentication, weather retrieval, alerts, and historical logging.
  • Asynchronous Worker Queue: Celery and Redis handle background task processing, caching, and database writes without blocking UI rendering.
  • Real-Time WebSockets: Flask-SocketIO pushes instantaneous severe weather alerts to connected clients.
  • Zero-Leak API Proxying: Sensitive API keys (OpenWeatherMap, Unsplash) are securely stored on the backend and are never shown or exposed to client browsers.
  • Vanilla CSS Glassmorphism: High-performance hardware-accelerated 3D animations and responsive glass cards without heavy CSS frameworks.
